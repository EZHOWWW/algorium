# Zeroth-Order Stochastic Gradient Descent (ZO-SGD)

This is an implementation of the Zeroth-Order Stochastic Gradient Descent (ZO-SGD) algorithm, also known as the Randomized Stochastic Gradient-Free (RSGF) method.

## Reference
- **Authors**: Saeed Ghadimi, Guanghui Lan
- **Title**: Stochastic First- and Zeroth-Order Methods for Nonconvex Stochastic Programming
- **Venue**: SIAM Journal on Optimization
- **Year**: 2013
- **URL**: https://epubs.siam.org/doi/abs/10.1137/12086731X
